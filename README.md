# Sales Performance Dashboard – Olist E-commerce Customer Analytics

## Project Overview

This project presents an interactive **Sales Performance Dashboard** developed in **Microsoft Power BI** using the **Brazilian E-commerce (Olist) Dataset**. The dashboard provides insights into sales performance, customer behavior, product categories, payment methods, and delivery performance through interactive visualizations and Key Performance Indicators (KPIs).

---

## Project Objective

The objective of this project is to analyze e-commerce sales data and transform raw data into meaningful business insights using Power BI. The dashboard helps stakeholders monitor sales trends, customer segmentation, product performance, and operational efficiency.

---

## Dataset

* **Dataset Name:** Brazilian E-commerce Public Dataset (Olist)
* **Source:** Olist
* **Time Period:** 2017–2018

## Data Cleaning

The dataset was cleaned using **Power Query** by performing:

* Removing duplicate records
* Handling missing values
* Correcting data types
* Formatting text values
* Renaming columns
* Creating calculated columns where required

---

## Data Modeling

Relationships were established between multiple tables using common keys such as:

* Order ID
* Customer ID
* Product ID

A star-schema model was created for efficient reporting.

## Business Insights

* Regular customers contribute the highest share of revenue.
* Credit Card is the most frequently used payment method.
* Revenue is concentrated in a few product categories.
* São Paulo (SP) records the highest number of orders.
* Revenue trends help identify seasonal sales patterns.
